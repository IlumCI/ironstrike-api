************************
About this documentation
************************

This documentation is written in reStructuredText and built with `Sphinx <https://www.sphinx-doc.org/>`_
and `python-docs-theme <https://github.com/python/python-docs-theme>`_, the theme of
docs.python.org, whose layout it follows.

The :ref:`reference-index` is generated by ``docs/tools/RefGen`` from ``IronstrikeApi.dll`` and its
``///`` comments. The build fails if a public member has no summary, so the reference cannot fall
behind the code.

To build it yourself, from the repository root::

   ./build-docs.sh          # Linux, macOS
   .\build-docs.ps1         # Windows

and open ``docs/_build/html/index.html``.

Most of what is known about the game comes from working on Ironstrike Trainer and Ironstrike
Servers: reading the IL2CPP metadata, disassembly, and a great deal of trial and error in the
running game. Facts in :ref:`internals-index` say when they were verified.

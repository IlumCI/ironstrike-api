######################
  The Mod API Tutorial
######################

This tutorial introduces the API by building a small mod, **Hello Mod**, one feature at a time. It
assumes you can read C#, and nothing about IRONSTRIKE, BepInEx or IL2CPP. The finished mod is in
the repository under ``examples/HelloMod``.

Each chapter adds one idea. You can stop after :ref:`tut-firstmod` and already have a working mod.
